# 한국어 문장

사실, 구조, 근거 준비를 먼저 마친 뒤 이 파일을 적용한다. 말투는 글마다 스펙에서 정한다.

## 대원칙

- **과교정 금지.** 의미·수식·코드·용어·직관 설명의 자연스러움은 건드리지 않는다. 문체만 조인다.
- **강박 금지.** 접속어를 0으로 만들거나 '것/의'를 전부 없애려 하지 않는다. 논리 전환에 꼭 필요한 것은 남긴다.
- **정확성 우선.** 짧게 쓰려고 조건, 논증 단계, 재현에 필요한 코드, 안정된 용어를 지우지 않는다.
- **문장 배열이 의미를 바꾸지 않게.** 문장을 쪼개거나 어순을 바꿀 때 조건은 결론 가까이에, 원인과 결과는 대응하는 자리에 둔다.
- 코드 주석·인용·수식 내부 텍스트는 대상이 아니다.

## 문장 연결 (길이보다 먼저 본다)

정보를 어디에 두고 어떻게 잇는지를 본다. 영어 어순 규칙을 옮기지 않고 원리만 쓴다.

- [ ] **같은 대상을 가리키는가.** 이어지는 문장이 같은 대상을 말하는지, 주어가 바뀌면 바뀐 것이 보이는지.
- [ ] **앞 결론이 다음 전제가 되는가.** 이미 말한 것을 문장 앞에, 새 정보를 뒤에 둔다. 다음 문장은 앞 문장이 끝낸 곳에서 시작한다.
- [ ] **조건이 결론 가까이 있는가.** "…일 때만"이 붙는 결론과 그 조건 사이에 다른 문장이 끼지 않게 한다.

## 문장 호흡과 주어·서술어

사용자 지적(2026-11-20)에서 온 규칙이다. `check_style.py`가 긴 문장, 쉼표로 이은 절, 맨 식별자의 후보를 뽑는다.

- [ ] **한 문장에 사실 하나.** 60자가 넘는 문장은 나눌 수 있는지 본다.
- [ ] **쉼표로 주어가 다른 절을 잇지 않는다.** 주어마다 서술어로 닫고 문장을 끊는다.
  - ✗ 「50 ms가 지나면 저장하는 방법은 간격이 50 ms보다 짧아질 수 없어서, n번 점을 잰 시각이 n×50 ms보다 늦어지기만 하고 당겨지지 않는다.」 — 주어 「방법은」이 맨 끝 「않는다」와 짝처럼 읽힌다.
  - ✓ 「이 방법에서 저장 간격은 50 ms보다 짧아질 수 없다. 그래서 n번 점을 잰 시각은 n×50 ms보다 늦어지기만 한다.」
- [ ] **주어와 서술어만 남겨 읽는다.** 주어가 그 서술어의 일을 할 수 있어야 한다. 「방법은 짧아질 수 없다」(✗) → 「간격은 짧아질 수 없다」(✓).
- [ ] **동작을 감춘 명사구를 푼다.** 「고른 측정의 시각」(✗) → 「고른 측정을 잰 시각」(✓). '의'가 무슨 관계인지 독자가 추측해야 하면 동사로 푼다.
- [ ] **처음 쓰는 낱말은 쓰기 전에 정의한다.** 일상어처럼 보여도 글에서 좁은 뜻이면 정의한다(예: 「측정 간격」 = 이웃한 두 측정을 잰 시각의 차이).
- [ ] **코드 이름은 인라인 코드로 쓴다.** 변수·함수·파일 이름: `base_dt`, `_resample_poses`.
- [ ] **쉬운 말이 뜻을 흐리면 정확한 명사를 쓴다.** 칸 → 구간, 어긋남 → 시각 차이·위치 오차, 길 → 경로.

## 군더더기

- [ ] 문두 접속어('그리고·그런데·그러나·따라서·하지만·그래서') 남발을 자제한다. 문장 순서와 인과로 대신한다.
- [ ] 불필요한 보조 용언("~해 보다", "~하고 있다"), 수식어, 복수 '-들'을 줄인다.
- [ ] 지시어('이·그·이러한')의 대상이 분명한지 본다.

## 중복

- [ ] 같은 단어 반복(의도적 강조가 아니면), 겹말('미리 예상'), 조사·어미 반복을 정리한다.
- [ ] 같은 용어는 끝까지 같은 말로 쓴다. 시리즈 용어 사전이 있으면 `check_terms.py`로 대조한다.

## 간결·우리말

- [ ] 의존 명사 '것'('~하는 것이다')과 관형격 '의'를 줄인다.
- [ ] 불필요한 표현을 걷어 낸다.

## human-writing에서 가져온 두 가지

- **구체적으로.** "크게 줄었다" 대신 "3쌍 1.1 mm → 30쌍 0.17 mm". 숫자는 `numbers.json`에 등록한다.
- **얼버무리지 않는다.** 확인한 것은 단정하고, 확인 못 한 것은 '확인 못 함'이라고 쓴다. "~일 수도 있다"로 흐리지 않는다.

## 장르 예외 (AI 티로 지우지 않는다)

수학·공학 해설에서 아래는 독자를 돕는 장치다. 문체 검토에서 지우라고 하지 않는다.

- 대응이 적힌 설명용 비유 (`explain-devices.md` 대응표)
- 글이 스스로 던지고 답하는 질문
- 단계를 하나씩 밟는 설명, "다시 말해"로 잇는 재진술
- 앞 절 내용을 짧게 다시 불러오는 문장
